支付安全变化：
- 易支付 V1 增加可选的订单主动查询配置，当前支持 ZPAY V1 查询接口。
- 支付回调通过原有签名校验后，可继续向支付服务商查询订单状态。
- 二次查询同时校验支付状态、商户订单号、商户号、支付金额和服务商交易号，确认不一致时不执行发卡。
- 后台支付渠道配置增加查询开关、查询地址、超时时间和订单查询测试功能；测试不会改变订单或发卡状态。
- 查询接口仅允许 HTTPS，拒绝本地地址，避免将查询凭证发送到本机服务。

本地开发变化：
- 修复支付渠道配置页面中 `configJson` 未定义导致的 TypeScript 构建错误。
- 保留 Docker Compose + PostgreSQL + Redis 部署方式，版本检查继续使用 Docker Hub 具体版本标签。
- 更新启动横幅、仓库地址和应用版本显示为 `dujiao-next-erkai`。
- 更新部署文档和版本记录，保留 `latest` 与具体版本标签。

UI 和移动端变化：
- 后台安全设置的三个密码输入框增加显示/隐藏密码按钮。
- 站点联系方式保留 Telegram，移除 WhatsApp，支持最多 3 个自定义联系方式，与 Telegram 合计最多 4 个。
- 自定义联系方式支持名称和链接，前台以两列布局展示，并在小屏幕回落为单列。
- 移除后台仪表盘广告区域及无用引用。
- 统一前后台项目仓库链接、版本信息和二开项目说明。

数据库或配置变化：
- 本版本不新增数据库迁移；支付查询配置保存在支付渠道配置 JSON 中。
